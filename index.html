quantlib-irs-toolkit

Live on PyPI: pip install quantlib-irs-toolkit

Minimal QuantLib helpers to bootstrap interest-rate swap curves for PLN, HUF, CZK, ZAR. Discount factors, zero rates, forward rates from market par swap rates. CI tested on Python 3.10/3.11/3.12, published via Trusted Publisher (OIDC).

Production-grade starter for a trading-floor Excel add-in: ribbon, MSAL Entra ID auth, HTTP back-end client, timer-driven cell watcher on named ranges, packaging scripts. Builds green on Windows via GitHub Actions.

proxmox-host-hardening

Shell script + docs

CIS-aligned hardening playbook for Proxmox VE 8 hosts. Idempotent script, dry-run mode, automatic backups, walkthrough, accepted-findings documentation (root SSH between cluster nodes, rpcbind for NFS, ...).
